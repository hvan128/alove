# Three-Minute Demo Script

1. Open `/console`. Point out the three source modes and the visible readiness badges.
2. Choose **Browser call** and start **Chạy demo đơn hàng**. Explain that the no-key scripted fixture is labelled `Demo cục bộ`; production uses VALSEA final events.
3. Advance through the Vietnamese/code-switching transcript: “Chị lấy 12 thùng cà phê Arabica, thêm 3 pack Oat Milk 1L.” The provisional line is visually different from final lines.
4. Show the draft: customer, two lines, evidence quotes and confidence. Open the ambiguous-alias exception, select the correct product, then correct quantity if desired.
5. Click **Duyệt đơn nháp**. The export control becomes enabled only after approval. Export once, then demonstrate the same idempotency key returns the same draft reference.
6. Review the suggested Vietnamese confirmation and click **Nói phản hồi**. The browser announces that this is AI/device-generated voice and speaks it.
7. Switch to **Zalo replay** and show that it is labelled replay, not a direct call. Switch to **Phone** and show Twilio provisioning requirements/document link.
8. Open `/design-system` to show reusable components and responsive design.
